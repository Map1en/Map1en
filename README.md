I like building software that people actually use.

I play VRChat, so right now that's [VRCX-0](https://github.com/Map1en/VRCX-0), a desktop companion for it. I rewrote it from scratch in Rust and React, and it comes with a built-in AI assistant and MCP server. Now and then I write about it on the [VRCX-0 dev blog](https://blog.vrcx-0.dev/en/).

Before that, I was a core maintainer of [VRCX](https://github.com/vrcx-team/VRCX).
